# 蝶希美羽（ちょうき みう）

<p align="center">
  <img src="images/chouki-miyu.png" alt="蝶希美羽" width="360">
</p>

蝶希美羽は、Windows向けに制作したオリジナルのデスクトップキャラクターアプリです。

デスクトップ上でキャラクターがアニメーションし、クリックやマウスの接近など、ユーザーの操作に応じて反応します。キャラクターデザイン、アニメーション素材、UIデザインおよびアプリケーションは、すべてオリジナルで制作しています。

## 主な機能

- 透過背景のデスクトップキャラクター表示
- 待機中のランダムアニメーション
- マウス接近時のリアクション
- クリック位置に応じたインタラクション
- キャラクターのドラッグ移動
- 常に手前に表示する機能
- 日本語・中国語・韓国語表示
- 設定画面
- ウィンドウ位置と設定内容の保存
- モーションを抑える表示設定

## 動作環境

- Windows 10 / Windows 11
- 64bit環境推奨

Pythonなどの開発環境を別途インストールする必要はありません。

## ダウンロード

[GitHub ReleasesからWindows版をダウンロード](https://github.com/chou12388/chouki-miyu/releases/latest)

## 起動方法

1. ZIPファイルを展開します。
2. `蝶希美羽.exe` をダブルクリックします。

> `蝶希美羽.exe` と `_internal` フォルダーは、必ず同じ場所に置いてください。

Windowsから警告が表示された場合は、ファイルの入手元を確認したうえで実行してください。

## 操作方法

- キャラクターをドラッグ：デスクトップ上を移動
- キャラクターをクリック：リアクションを再生
- マウスを近づける：接近リアクションを再生
- 設定アイコン：表示や動作を変更

## 使用技術

- Python
- PySide6 / Qt
- PyInstaller
- FFmpeg
- WebM透過アニメーション
- JSONによる設定保存

## 技術的なポイント

- 枠のない透過ウィンドウによるデスクトップ表示
- キャラクターアニメーションと操作判定の連携
- ランダム待機モーションの制御
- 多言語UIとフォントの切り替え
- ユーザー設定とウィンドウ位置の永続化
- PyInstallerによるWindows向けアプリケーション配布

## 注意事項

- 本アプリはWindows専用です。
- `_internal`フォルダーを削除または移動すると起動できません。
- 本配布ファイルはポートフォリオ確認を目的としています。
- 動画、画像、音声などの素材を無断で再配布・転載は禁止利用しないでください。
